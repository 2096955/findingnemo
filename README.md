# Whale Agent

An open-source agentic system to **reduce whale-vessel collisions at scale**, built on [Solace Agent Mesh](https://github.com/SolaceLabs/solace-agent-mesh) for [Project Resilience](https://project-resilience.github.io/platform/projects/whale_agent.html).

Aligned with **UN SDG 14** (Life Below Water) and **SDG 09** (Industry, Innovation, Infrastructure).

> **Project page:** <https://project-resilience.github.io/platform/projects/whale_agent.html>
> **Discussion:** <https://github.com/Project-Resilience/platform/discussions/91>

---

## What It Delivers

### 1. Dynamic Risk Map

A real-time collision risk heatmap covering vessel-whale interaction zones, updated as environmental and traffic conditions change.

<!-- Screenshot: Dashboard showing the Deck.gl risk heatmap layer (red/yellow/green) overlaid on the Pacific coast -->
![Risk Heatmap](docs/screenshots/risk-heatmap.png)

- Color-coded collision probability from teal (low) to red (critical)
- Fed by the **RiskAssessor** agent using whale density, vessel traffic, speed, and seasonal factors
- Powered by NOAA, Open-Meteo, GBIF, and Marine Cadastre data via MCP servers

### 2. Optimized Shipping Routes

Dynamic, seasonal shipping routes optimized to minimize whale strikes while balancing fuel cost and delay.

<!-- Screenshot: Dashboard showing the green recommended route avoiding red risk zones -->
![Optimized Route](docs/screenshots/optimized-route.png)

- Weighted A* pathfinding that avoids high-risk whale zones
- Fuel impact and delay estimates for every route diversion
- Origin/destination/date input with season and species filters

### 3. Warnings & Recommendations

Timely alerts for speed reduction, course adjustment, and increased situational awareness in higher-risk areas.

<!-- Screenshot: Sidebar showing Active Alerts with speed restrictions and Risk Summary panel -->
![Alerts & Recommendations](docs/screenshots/alerts-sidebar.png)

- Speed reduction zones with max knot limits and reasons
- Risk summary: collision probability %, fuel impact %, estimated delay
- Recommendations generated by the orchestrator from specialist analysis

## Context / Actions / Outcomes

All data follows the [Project Resilience decision framework](https://project-resilience.github.io/platform/):

### Context (Input Data)

| Attribute | Source | Implementation |
|-----------|--------|----------------|
| Ship type | User input | Route query form |
| Ship location | User input / AIS | Origin/destination ports |
| Collision risk map | Computed | `risk_scorer` tool (whale density x vessel traffic x speed x season) |
| Vessel traffic | Marine Cadastre MCP | `traffic_density` tool aggregates AIS data |
| Weather conditions | NOAA + Open-Meteo MCP | `WeatherAnalyst` agent (SST, waves, wind, currents) |
| Season | User filter / auto-detected | Sidebar season dropdown, seasonal multipliers in risk model |
| Whale spotting areas | Whale Alert + GBIF MCP | `WhaleMigrationTracker` + `HabitatAnalyst` agents |
| Krill spotting areas | GBIF + habitat models | `habitat_mapper` tool (feeding ground hotspots) |

### Available Actions

| Action | How It Works |
|--------|-------------|
| Dynamically adjust shipping routes | `route_calculator` computes whale-safe waypoints with A* pathfinding |
| Suggest protection areas | `habitat_mapper` identifies feeding/breeding hotspots, rendered as map layers |
| Reduce speed in high-risk zones | `risk_scorer` generates speed reduction recommendations per zone |
| Adjust ship's course | Route layer shows recommended vs. standard route on the map |
| Increase situational awareness | Real-time whale sighting markers + migration corridor overlays |

### Outcome Metrics

| Metric | Displayed In |
|--------|-------------|
| Crew safety | Risk level (LOW / MODERATE / HIGH / CRITICAL) per route segment |
| Whale strike minimization | Collision probability % in Risk Summary panel |
| Fuel consumption | Fuel impact % (diversion cost) in Risk Summary panel |
| Delays | Estimated delay hours in Risk Summary panel |

## Quick Start

```bash
# Clone and enter project
git clone <repo-url> whales && cd whales

# One-command setup (creates venv, installs deps, starts everything)
bash scripts/dev.sh

# Access:
#   Frontend:  http://localhost:3000
#   Gateway:   http://localhost:8080
#   Chat:      http://localhost:3000/#/chat
#   Dashboard: http://localhost:3000/#/dashboard
```

### Prerequisites

- Python 3.10+
- Node.js 18+
- API keys in `.env` (copy from `.env.example`):
  - `GEMINI_API_KEY` or `ANTHROPIC_API_KEY` (LLM provider)
  - `WHALE_ALERT_API_KEY` (whale sighting data)
  - `IUCN_API_KEY` (conservation status)

### Manual Setup

```bash
# Backend
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
cp .env.example .env  # fill in API keys

# Start MCP servers
bash scripts/start_mcp_servers.sh &

# Start agents + gateway
bash scripts/start_agents.sh &

# Frontend
cd client/webui/frontend
npm install
npm run dev
```

## Dashboard

The Dashboard (`/#/dashboard`) provides the primary decision-making interface:

<!-- Screenshot: Full dashboard view showing map + sidebar together -->
![Full Dashboard](docs/screenshots/full-dashboard.png)

| Panel | Purpose |
|-------|---------|
| **Route Planning** | Origin/destination port input with departure date |
| **Filters** | Season and species dropdowns — injected into agent queries |
| **Risk Summary** | Collision probability %, fuel impact %, delay estimate |
| **Active Alerts** | Speed reduction zones with max knot limits |
| **Map Layers** | Toggle checkboxes for all 5 visualization layers |

### Map Layers

| Layer | Data Source | Visualization |
|-------|-----------|---------------|
| Risk Heatmap | `risk_scorer` → `map_renderer` | HeatmapLayer (teal→red gradient) |
| Whale Sightings | Whale Alert + GBIF MCP → `map_renderer` | ScatterplotLayer (blue dots with tooltips) |
| Shipping Lanes | Marine Cadastre MCP → `traffic_density` | PathLayer (gray semi-transparent) |
| Recommended Routes | `route_calculator` → `map_renderer` | PathLayer (emerald green) |
| Migration Corridors | `migration_model` → `map_renderer` | PathLayer (indigo dashed) |
